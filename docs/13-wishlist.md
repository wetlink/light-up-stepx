# 许愿池

整理于 2026-11-11

这里把大家想要的东西摆到明面上：希望官方开放的能力、希望有人做的应用和教程、用着不顺的地方。官方的问题与建议收集表提交之后，别人看不到提了什么；这里的每一条愿望所有人都看得到，可以补充自己的场景、附议。社区成员看到自己能做的，可以直接认领去做。

许愿只要一句话，想展开再多写几句；在交流群里喊一句也算，维护者会帮忙记进看板。

愿望的正本在多维表格「许愿池看板」里，本页只放入口和流转说明。

## 愿望怎么流转

新提交 → 讨论中 → 有人认领 / 已转官方 → 已实现

- **新提交**：刚从表单交上来，或者维护者从交流群里代记的，还没整理。
- **讨论中**：维护者看过了，大家在补充场景，判断能不能做、该由官方还是社区来做。
- **有人认领**：社区里有人说要做，看板上写着认领人，做到哪了写在进展备注里。
- **已转官方**：只有官方能做的，维护者已经提交到官方的收集表；"官方渠道"一栏记着有没有提交、官方有没有回应。
- **已实现**：官方开放了，或者社区做出来了，进展备注里写怎么用、在哪找。
- **暂不做**：重复的、目前做不到的或暂时没人推进的，放在这一列，不删除。

新提交的愿望由维护者整理：补上类型，把补充说明拆进场景、现状、希望，判断谁能做。所以许愿的人不用操心格式。

**认领**：看到自己能做的，在交流群里说一声，或者在本页评论，写明是哪一条；维护者把你的昵称填进"认领人"，状态改成"有人认领"。想找能直接动手的，看看板里的"社区可做"视图。

**附议**：你也想要某一条，同样在交流群里或本页评论里说一声，最好补一句你的场景；维护者给它的"热度"加一。看板每一列按热度从高到低排。

## 怎么把需求送到官方

写在这里方便大家补充，但官方不一定会来看。想让官方直接收到，可以同时走官方的两个入口：

- **STEPX Neo 问题&建议搜集表**：[链接](https://bbp.bluebc.cn/f/pNbCZ9)。在"具体内容"里写清场景、现状和希望，可以附截图或视频。
- **手机里的"设置 > 帮助与反馈"**：更适合手机本身的问题，可以选模块、附日志。

两个入口的细节见 [官方资料入口](16-official-resources.md)。
