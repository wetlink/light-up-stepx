# 怎么参与

整理于 2026-11-10

本知识库是非官方的，由 StepX Neo 玩家和开发者自发整理，与 StepX 官方没有隶属关系。文中提到的产品名称归各自所有者。

## 纠错

发现写错了、过时了，直接在对应文档里选中那段文字评论，写清哪里不对、你看到的是什么、在什么系统版本上。

## 投稿

有实测结论或踩坑经历，按下面的格式整理好，目前先贴在本页的评论里；以后有了正式的投稿渠道，会在这里更新。

```
标题：一句话说清是什么，比如"背屏推帧每秒 6 帧会掉帧吗"
实测环境：机型 · 系统版本 · 日期，比如 StepX Neo · Step AOS 1.0.0.2 · 2026-11-10
步骤：你做了什么，按顺序写，别人照着能重复
结果：看到了什么，有报错就原样贴上
未验证的部分：哪些是推测、哪些没试，单独列出来
```

## 内容约定

- 只写实测过或有出处的内容，并标明测试时的系统版本。
- 做不到的事直接写做不到，有替代办法就一起写上。
- 不写绕过系统限制的方法。
- 分清来源：文中用【实测】表示自己在真机上试过，【官方】表示来自官方页面或文档，【Studio 回答】表示 Studio 在对话里的回答，【未验证】表示还没确认。
- 不贴设备序列号、账号、密钥、调试链接和任何人的联系方式。
