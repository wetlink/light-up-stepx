# 常见问题

实测环境：StepX Neo · Step AOS 1.0.0.2 · 2026-11-10 · 按官方资料校对于 2026-11-11

官方有一份《StepX Neo 常见问题 FAQ》，覆盖连接、通话、耗电、发热、声音、充电、第三方应用等约 190 个问题，入口和摘要见 [官方资料入口](16-official-resources.md)。官方 FAQ 已经回答的问题，这里不重复；这页只收我们实测遇到、官方资料里没有覆盖的问题。

## 怎么向官方反馈问题

【官方】有两个入口：

- **手机里的"设置 > 帮助与反馈"**：适合手机本身的问题。可以选问题所属的模块，需要时开启手动抓取日志，复现一次再提交。官方 FAQ 的大部分答复最后都指向这里。
- **STEPX Neo 问题&建议搜集表**：[链接](https://bbp.bluebc.cn/f/pNbCZ9)。要填设备绑定的手机号、身份或职业、具体内容，可以附截图或视频。表单没有分类字段，具体内容里写清是哪一类问题、系统版本和复现步骤。

希望官方开放的开发能力，也可以写进 [许愿池](13-wishlist.md)。

## 为什么不能用自己的照片当壁纸

【实测】系统的壁纸页只能选内置壁纸，系统相册里也没有"设为壁纸"。这是这台手机目前的系统设计，不是设置没找到。截至 2026-11-11，官方的 FAQ、Step Studio 知识库和更新说明里没有提到自定义壁纸。

现在的办法是装一个能设壁纸的第三方应用。社区做了一个叫 StepX 装扮的原生应用，能选图、裁剪、压暗后设为锁屏或桌面，目前是测试版，获取方式待公布。详见 [换壁纸](03-wallpaper.md)。

想换回原装的动态壁纸：设置 → 桌面、壁纸和个性化 → 壁纸，重新选一个内置壁纸。

## 用电脑装应用为什么老是失败

【实测】用 USB 连电脑安装应用时，手机每次都会弹出"正在通过USB自动安装以下应用"，让你选禁止或允许。大约 15–30 秒没人点，就按拒绝处理，电脑上会看到 `INSTALL_FAILED_USER_RESTRICTED`。

办法：安装时把手机拿在手里，弹窗出来就点"允许"。这一步没法无人值守。

## Studio 做的应用为什么做不了语音转文字

【实测】Studio 的连接器列表里没有语音识别。有"麦克风与录音"，但没有把语音转成文字的连接器。截至 2026-11-11，官方的 FAQ、Step Studio 知识库和更新说明里没有提到语音识别对开发者开放。

替代办法：

- 让用户在输入框里用输入法自带的语音输入，应用拿到的就是文字。
- 自己录音后接第三方语音识别服务。这需要联网和你自己的服务账号，我们没有在 Studio 应用里试过。

希望官方提供语音识别连接器，已写进 [许愿池](13-wishlist.md)。

## Studio 真机测试扫码，提示"测试暂不可用"

【未解决】我们遇到过：在 Studio 项目里打开"真机测试"，用手机扫码后提示"测试暂不可用"。原因没有查明。

【官方知识库】真机测试的方式按作品类型不同：应用是获取体验安装包，装到安卓真机上测试；智能体扫码后，到手机的 Amoo 空间（桌面右滑或上拉）→ 设置 → 我的作品 → 智能体里安装；技能扫码后，到 Amoo 空间 → 设置 → 测试空间 → 技能里添加，单个作品最多 20 人测试。知识库里没有提到"测试暂不可用"这个提示。

可以试试：确认测的是哪类作品、按上面的方式找入口；重新发起一次真机测试，二维码出来后立即扫码。如果你找到了原因或稳定的解决办法，欢迎补充到 [踩坑记录](14-pitfalls.md)。
