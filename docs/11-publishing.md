# 上架

整理于 2026-11-11

StepX Neo 上的作品有两条上架渠道：Step Studio 做的应用、智能体、技能走 **AmooStore**；传统安卓安装包走 **STEPX 开发者中心**，进手机自带的应用商店。

本文整理自《Step Studio 官方知识库》（在官方开发者群公告的文档合集里，见 [官方资料入口](16-official-resources.md)）和 STEPX 开发者中心的文档。我们自己还没有走完一次完整的上架，审核细节以官方为准。

## 两条渠道对照

| | AmooStore | 手机应用商店 |
|---|---|---|
| 收什么 | Step Studio 做的应用、智能体、技能 | 传统安卓安装包（原生应用） |
| 在哪提交 | 在 Step Studio 里，作品发布后提交 | STEPX 开发者中心（developer.stepaos.com），用 STEPX 账号登录 |
| 用户在哪用到 | 手机里的 Amoo 空间 → AmooStore | 手机自带的应用商店 |
| 实名认证 | 开发者个人实名认证，在 Studio 的设置里办 | 开发者中心自己的实名认证 |
| APP 备案 | 官方知识库里没有提到 | 每个新应用上架前都要完成 |
| 出处 | 《Step Studio 官方知识库》 | 开发者中心文档 |

## 先分清：发布不等于上架

在 Step Studio 里，"发布"是生成一个正式版本，不需要上架审核；"上架"是把作品提交到上架渠道，按平台规则通过审核。知识库原话："发布不等于上架。生成正式版本后，不代表作品已在市场中公开展示。"

另外两点：

- 后续修改作品，要重新测试并发布，才会更新用户在用的版本。
- 开发环境和正式环境的数据互相独立，开发版本里的测试数据不会自动变成正式数据。

## AmooStore：Step Studio 的作品

三类作品的规则不一样，下面分开说。出处都是《Step Studio 官方知识库》。

### 应用

- 自测通过后点"发布"，确认作品和版本信息，生成正式版本。
- 发布后可以私域分享：在版本管理里选一个可访问的正式版本，点"分享"，把链接或二维码发给别人。
- 要上架：选正式版本，点"提交到 AmooStore"，按要求上传上架材料，等待审核。
- 需要完成开发者个人实名认证。
- 审核通过后，应用出现在手机 Amoo 空间里 AmooStore 的"AI 应用"栏。
- 上架后不支持回滚。
- 发布前系统会检查构建产物、签名、环境变量、密钥和数据库结构变更；提示有问题时，逐项修好后重新生成正式版本再发布。

### 智能体

- 发布和上架是同一个动作。
- 前置条件：完成实名认证（未成年不可上架），勾选并签署开发者协议。
- 所有上架 AmooStore 的智能体都要审核；通过后，所有用户都能在 AmooStore 搜到并使用。
- 审核过程中可以撤回，撤回后能重新提交最新版本。

### 技能

- 分两步：先发布，再上架。
- 发布：通过前置校验（实名、未成年、协议）和机器审核后，技能就能在智能体构建器和应用构建器里被配置调用。
- 上架：对已发布的技能点"上架"，经人工审核通过后进入 AmooStore，手机端用户也能把它配置给 Amoo 使用。审核过程中可以撤回。
- 只发布不上架，其他用户在手机上用不到它。

### AmooStore 要不要 APP 备案

截至 2026-11-11，《Step Studio 官方知识库》里没有提到 AmooStore 上架是否需要 APP 备案。我们不知道答案，有确切消息欢迎补充。

## 手机应用商店：传统安卓安装包

适用于原生安卓应用，能做什么见 [原生安卓应用能做什么](10-native-android.md)。以下整理自开发者中心的页面与文档。

### APP 备案

每个新应用上架前，都要先完成工信部的 APP 备案。在开发者中心填的包名、证件信息，必须和备案信息一致。

所以包名要在备案前定下来，备案之后就不能随便改了。应用名里如果用到 StepX 这类品牌词，建议先向官方确认能不能用。

### 准备安装包

- 只收 64 位的安装包。
- 用正式签名打包。

### 在开发者中心提交

用 STEPX 账号登录开发者中心，菜单有：应用管理、数据统计、账户管理、完善信息、文档。点"发布新应用"，第一步是上传安装包。

### 审核会驳回的情况

开发者中心的文档里列出的包括：

- 打开就提示更新
- 闪退
- 主要功能没有响应

### 审核通过之后

应用进入手机自带的应用商店，用户在那里下载。开发者中心的文档还提到，经认可的收费软件可以分成，细则以官方为准。

## 账号与认证

| 渠道 | 在哪登录 | 实名认证 |
|---|---|---|
| AmooStore | Step Studio（studio.stepx.com），手机号加短信验证码 | Studio 的 设置 → 账号管理 → 开发者认证，页面写的是"预计 1–3 个工作日完成审核" |
| 手机应用商店 | STEPX 开发者中心（developer.stepaos.com），STEPX 账号 | 开发者中心自己的实名认证 |

两边的认证是什么关系、能不能互通，官方资料没有说明。

## 更正说明

这页之前写过"Studio 做的应用要构建成带正式签名的安装包，上传到开发者中心，包名也要单独备案"；Studio 里的 AI 也回答过"AmooStore 只收技能和智能体"。这两种说法都和《Step Studio 官方知识库》不一致，已按官方改正：Studio 做的应用、智能体、技能都走 AmooStore。
