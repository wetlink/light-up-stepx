# 连接器能力表

实测环境：StepX Neo · Step AOS 1.0.0.2 · 2026-11-10

连接器是 Studio 应用拿到手机系统能力的入口：项目里添加了哪个连接器，应用才能调用它的能力。目前 Studio 里能看到 34 个，分 5 组。

## 怎么添加

两个地方都可以：

- 新建项目时：在 Studio 首页的输入区点"添加 → 连接器"，选好再开始对话。
- 已有项目：在项目的 配置 → 集成 → 添加更多集成 里选。

每个连接器都有详情页，写着概览、能力说明表、类别、版本和开发者。添加之前建议先点进去看它到底包含哪些能力。

添加后，Studio 会在工程里登记这个连接器（我们的项目里是根目录下的 `capability.json`）。生成过程中 Studio 有时会自己增删登记，每轮生成后最好核对一下，见 [踩坑记录](14-pitfalls.md)。

## 列表里没有的

- 壁纸：搜"壁纸"没有结果。
- 语音识别：没有把语音转成文字的连接器。

替代办法见 [能与不能（实测清单）](08-can-and-cannot.md)。

## 授权

【Studio 回答】"背面点阵屏"和"通用原子能力"两个连接器的认证类型是 none，不需要登录或填密钥，Studio 平台这一侧不弹授权框。【未验证】手机系统这一层调用时会不会弹确认，以及其他连接器需不需要授权，还没逐个确认。
