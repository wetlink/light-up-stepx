# 背面点阵屏连接器详解

实测环境：StepX Neo · Step AOS 1.0.0.2 · 2026-11-10

"背面点阵屏"连接器在 StepX 手机硬件分组里，详情页显示版本 1.0.2、开发者 STEPX。【Studio 回答】认证类型为 none，平台侧不弹授权框。

只做背屏的应用挂这一个连接器就够了。"通用原子能力"里也带一组背屏能力，但同时会给应用很多别的能力，用不到就不要挂。

## 自定义文本的规则

【官方】内置字库只支持大写 A–Z、数字 0–9、`! - ?` 三个符号和空格，共 40 个字符，小写自动转大写。含中文时最多 6 个字，由系统转成点阵显示。

## 推图案的数据格式

【官方】画布固定 17 列 × 23 行，共 391 格。一帧是长度为 391 的整数数组，每个值是这一格的亮度，0–255，0 为灭。第 x 列、第 y 行（都从 0 开始）的点在数组里的下标是 `y × 17 + x`。

```js
const W = 17, H = 23;
const frame = new Array(W * H).fill(0);   // 391 个 0
frame[y * W + x] = 255;                   // 点亮第 x 列、第 y 行
```

【未验证】下标 0 对应背屏的哪个角，以真机为准，我们还没专门核对过方向。

详情页有一处不一致：概览说这项能力只接受图案数据，能力表又说图案数据和文字二选一。我们只用图案数据实测过。要显示文字，建议用"设置背屏待机显示类型"的自定义文本。

## 清除要用清除能力

要把背屏恢复原来的显示，调用"清除背屏自定义图案显示"。不要推一帧全零的图案来代替：全零帧只是一张全黑的图，不会退出自定义图案模式。【官方】这一点能力说明里有写；我们没有专门对比测试过全零帧的效果。

## 动画

- 【Studio 回答】可以连续推帧做成动画。帧率上限、有没有节流、支不支持局部刷新，官方都没写，Studio 也回答"不确定"。
- 【未验证】社区的应用目前按每秒 1–6 帧设计（默认 3 帧），两次推送至少间隔 300 毫秒，真机上的实际节奏还没测。
- 建议某一帧推送失败就停下并提示，不要无限重试。

## 保持显示

- 【实测】图案推上去后会一直保持显示。
- 【未验证】长时间放置、重启之后是否还在。
