# 踩坑记录

实测环境：StepX Neo · Step AOS 1.0.0.2 · 2026-11-10

我们踩过的坑。每条写现象、原因、办法；原因没查明的直接写没查明。

## USB 安装确认超时

- **现象**：用 USB 连电脑装应用，总是失败，电脑上报 `INSTALL_FAILED_USER_RESTRICTED`。
- **原因**：手机每次 USB 安装都会弹"正在通过USB自动安装以下应用"，让你选禁止或允许。大约 15–30 秒没人点，就按拒绝处理。
- **办法**：安装时把手机拿在手里，弹窗出来点"允许"。不要把安装当成无人值守的步骤。

## Studio 文件面板首次打开显示"暂无文件"

- **现象**：刚打开项目的文件面板，显示"暂无文件"。
- **原因**：没查明。看起来像是云端环境还在启动。
- **办法**：稍等十几秒再刷新或重新打开，通常就正常了。

## 真机测试提示"测试暂不可用"

- **现象**：在 Studio 打开真机测试，手机扫码后提示"测试暂不可用"。
- **原因**：没查明。
- **办法**：可以试试重新发起真机测试，二维码出来后立即扫码。状态：未解决。

## 后台应用被回收，内存里的状态丢失

- **现象**：原生应用切到后台再切回来，页面重新加载，之前的操作记录不见了。
- **原因**：Step AOS 会冻结、回收后台应用，页面被重建。
- **办法**：状态保存到页面的保存状态里，记录写到应用自己的存储里，不要只放内存。详见 [原生安卓应用能做什么](10-native-android.md)。

## Studio 输入框会合并换行

- **现象**：把写好的多行需求粘贴进 Studio 的输入框，换行被合并了。
- **原因**：输入框的行为，原因没查明。
- **办法**：粘贴后检查一下；需求用编号和小标题来写，即使换行被合并也还读得懂。

## Studio 可能自行增删连接器登记

- **现象**：一轮生成之后，项目里登记的连接器和之前不一样了。我们遇到过 Studio 在改版时自己去掉了一个连接器的登记。
- **原因**：Studio 生成代码时会按它对需求的理解调整登记。那一次它的判断是对的（去掉的连接器确实用不到），但不一定每次都对。
- **办法**：每轮生成后，核对项目登记的连接器，以及它在汇报里写的"用到了哪些能力"。
